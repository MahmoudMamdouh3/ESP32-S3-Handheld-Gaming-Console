1. Hardware & Pins

Physical connections: 2.4" ST7789 display (SPI), 12 input buttons, MicroSD card reader on shared bus, and power rails.

2. Firmware Drivers (`src/core/`)

The bridge between raw hardware and emulators: handles atomic button scanning, SPI bus arbitration, ROM streaming, and animated BMO expressions.

3. The 14 Engines

Self-contained console emulators adapted for the ESP32-S3: each core reads buttons, runs CPU cycles, and pushes audio/video frames.

4. Guardian Safety Suite

Static analyzers, memory profilers, bus calculators, and the web simulator that prevent physical hardware bugs before flashing.
